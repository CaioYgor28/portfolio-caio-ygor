# Caio Ygor — Software Developer Portfolio

A personal portfolio focused on backend development, systems integration, Python automation, and selected full-stack work.

**Live website:** https://portfolio-caio-ygor.pages.dev/

## About

I'm a software developer based in Brazil, experienced in Python, REST APIs, webhooks, SQL, Selenium, and enterprise workflow automation. This portfolio documents selected projects, engineering decisions, and professional experience.

## Selected projects

- **Caio & Luana:** a wedding platform developed for a real event, involving guest management, RSVP, payments, and administrative workflows. The production website has since been decommissioned. No private guest or transaction data is shared.
- **Igreja VEM:** a full-stack proof of concept for church and community management, using Django, PostgreSQL, React, and TypeScript.
- **RetailOps:** a collaboratively developed retail operations system with a Go API, React web interface, and React Native / Expo mobile app. Co-developed with Andrew Benvenuto.

Some project source repositories may be private or unavailable; the portfolio does not claim they are publicly accessible.

## Built with

React, TypeScript, Vite, CSS, and Lucide React icons. The site is static and can be deployed on Cloudflare Pages.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Vite outputs a static build in `dist/`.

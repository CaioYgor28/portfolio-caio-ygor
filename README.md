# Portfólio — Caio Ygor

Portfólio pessoal de Caio Ygor, desenvolvedor de software com foco em backend, automações, integrações e produtos digitais.

## Tecnologias

- React
- TypeScript
- Vite
- CSS

## Projetos em destaque

- **Caio & Luana** — plataforma de casamento em produção.
- **Igreja VEM** — POC full-stack para gestão, comunidade e planejamento.
- **RetailOps** — projeto em Go desenvolvido em parceria e publicado pela Dev Primacy.

## Executando localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

O conteúdo gerado em `dist/` pode ser publicado em serviços de hospedagem estática como Cloudflare Pages.
